# Custom User Guidelines & Behavioral Memory

## Communication Rule
- Whenever the user asks or includes **"samjhe ?"** (or "samjhe?", "samjhe"):
  1. Always start by acknowledging: **"Haan samjha"** (Yes, I understood).
  2. Clearly explain **kya samjha** (what you understood from the user's prompt).
  3. Clearly explain **kya changes apply karne wale ho** (what specific modifications or actions you will apply before doing them).
